# EduMotion Manual Question Builder

Isi paket:
- `manual-question-builder.html` — interactive frontend prototype.
- `manual-question-builder-spec.md` — product, workflow, schema, API, security, dan acceptance criteria.

Buka HTML di browser. Prototype menggunakan Tailwind CDN untuk preview dan belum terhubung ke backend. Untuk production, gunakan Tailwind build lokal yang dipin versinya, API LoopBack 4, storage media, dan workflow review server-side.
