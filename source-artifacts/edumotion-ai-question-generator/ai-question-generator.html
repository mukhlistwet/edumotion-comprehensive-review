Agent orchestration

Model dipilih melalui provider router. Peran agent dan tools dibatasi per tahap.

Agent pipeline
1. Planner — pecah kompetensi menjadi blueprint dan variasi indikator.
2. Generator — hasilkan item sesuai schema, satu item per object.
3. Verifier — hitung ulang, cek simbolik, unit/dimensi, dan distractor.
4. Quality reviewer — cek bahasa, ambiguitas, level kognitif, duplikasi.
5. Human review — author/reviewer menyetujui atau meminta revisi.
Agent hanya boleh memanggil tools allowlisted: schema validator, math evaluator, unit checker, similarity search, curriculum lookup. Tidak ada arbitrary code execution.
