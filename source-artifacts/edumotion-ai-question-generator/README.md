# EduMotion AI Question Generator

- `ai-question-generator.html`: interactive UI prototype (generation is simulated; no live LLM call).
- `ai-question-generator-spec.md`: product, agent workflow, schema, API, data model, quality gates, security, and acceptance criteria.

Open the HTML file in a modern browser. Tailwind CDN is used for prototype preview only; production must use the pinned local Tailwind build.
