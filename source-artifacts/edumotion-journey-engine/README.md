# EduMotion Journey Experience Engine

Isi paket:
- `journey-experience-engine.html` — prototype interaktif multi-template.
- `journey-experience-engine-spec.md` — spesifikasi produk, arsitektur, API, data model, keamanan, dan acceptance criteria.

Buka HTML di browser modern. Prototype berjalan lokal di sisi frontend; data progress hanya simulasi dan akan reset saat halaman di-refresh.
