# EduMotion Adventure Learning Map

- `adventure-learning-map.html`: interactive game-like journey map with winding road, avatar, checkpoint nodes, mission panel, practice modal, XP reward, and Adventure / Board Game visual switch.
- `adventure-learning-map-spec.md`: interaction and production engineering specification.

Open the HTML in a modern browser. This is a frontend prototype; progress and rewards are simulated locally, not persisted or verified by a backend.
