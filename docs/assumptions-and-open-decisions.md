## 2. Resolusi Keputusan Terbuka (`OPEN-01` s.d. `OPEN-05`)

1. **Kebijakan Replay XP (`OPEN-01` → Terselesaikan Default Konservatif):** Penyelesaian pertama node berstatus belum selesai memberi 100% `rewardPreview.xp`; mengulang node `completed` memberikan `0 XP` (idempotent anti-farming) di backend maupun mock. Kebijakan persentase kooldown tambahan disiapkan via konfigurasi policy server tanpa mengubah API.
2. **Kebijakan Rilis Hasil Ujian & Pembahasan (`OPEN-02` → Terselesaikan via `release_at`):** Asesmen mengikuti timestamp `release_at` pada tabel `assessments` (`immediate` jika `release_at <= NOW()`, atau ditahan `resultsReleased: false` sebelum jadwal tiba seperti pada UTS Fisika).
3. **Ambang Batas Kuota AI & Tier Paket (`OPEN-03` → Terselesaikan via Policy Kolom & Cap):** `budgetCapUsd` (default `$1.00`) ditegakkan di backend `aiGeneratorService`; paket `family` dimodelkan melalui relasi many-to-many terbatas di `parent_student_links` (maks. 4 anak default).
4. **Kebijakan Privasi Anak & Persetujuan Orang Tua (`OPEN-04` → Terselesaikan Safe-by-Default):** `is_minor = true` (SD/SMP atau usia < 18) otomatis menyamarkan nama publik di `/leaderboard` hingga `privacy_opt_in_public_name = true` & izin orang tua terpenuhi.
5. **Integrasi Editor Rumus Mobile (`OPEN-05` → Terselesaikan):** Mempertahankan keypad simbol matematika ringan + render KaTeX + evaluator aljabar deterministik di `@edumotion/domain` agar ringan pada perangkat Android spesifikasi rendah.
